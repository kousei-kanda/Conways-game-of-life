# ライフゲーム（MATLAB）

セル・オートマトン「ライフゲーム」のシミュレーションです。
100×100 の盤面を `spy` で表示しながら世代を進めます。

| ファイル | 種類 | 内容 |
| --- | --- | --- |
| `LifeGame.m` | 普通のライフゲーム | グライダーとパルサーを置いて動きを観察する |
| `LifeGame_convergence_conway.m` | 収束の値を調べたもの | Conway の標準ルール。生存セル数の推移をグラフにする |
| `LifeGame_convergence_custom.m` | 収束の値を調べたもの | ルールを変えた版（誕生 3〜6 / 生存 2〜5）。生存セル数の推移をグラフにする |

## 実行方法

このフォルダを MATLAB のカレントフォルダにして、コマンドウィンドウでファイル名を入力します。

```matlab
LifeGame
LifeGame_convergence_conway
LifeGame_convergence_custom
```

途中で止めたいときは `Ctrl + C` を押してください。

## 基本ルール（Conway のライフゲーム）

各セルは「生」か「死」のどちらかで、周囲 8 マスの生きているセルの数で次の状態が決まります。

- **誕生**：死んでいるセルの周囲にちょうど 3 個の生きたセルがあると、生きたセルになる
- **生存**：生きているセルの周囲に 2 個または 3 個の生きたセルがあると、そのまま生き残る
- **死滅**：それ以外（1 個以下＝過疎、4 個以上＝過密）は死ぬ

※ 盤面の外周 1 マスは隣接セルを数えない作りのため、外周のセルは常に死んだ状態になります。

## LifeGame.m（普通のライフゲーム）

決まったパターンを置いて、Conway のルールで動きを観察します。

- **グライダー** ×4：四隅に置いた、斜めに移動していくパターン
- **パルサー** ×4：内側に置いた、周期 3 で形が変わり続ける振動子
- （ブリンカー `B` も定義されていますが、配置の行はコメントアウトされています）

| 変数 | 値 | 意味 |
| --- | --- | --- |
| `gridSize` | 100 | 盤面のサイズ |
| `timeframe` | 1000 | 進める世代数 |
| `pause(...)` | 0.01 | 1 世代ごとの待ち時間（秒） |

---

## LifeGame_convergence_conway.m / LifeGame_convergence_custom.m（収束の値を調べたもの）

ランダムな初期状態からシミュレーションを行い、各世代の **生存セル数**（`nnz(map)`）を `nz_count_history` に記録します。
全世代の計算が終わると、生存セル数の推移がグラフで表示されます。
グラフが横ばいになったところの値が、収束した値です。

2 つのファイルの違いは次のとおりです。

| | `LifeGame_convergence_conway.m` | `LifeGame_convergence_custom.m` |
| --- | --- | --- |
| ルール | Conway の標準ルール | ルールを変えたもの |
| 誕生する条件（死んだセル） | 周囲がちょうど 3 | 周囲が 3〜6 |
| 生存する条件（生きたセル） | 周囲が 2〜3 | 周囲が 2〜5 |
| 初期の生存率 `init_rate` | 0.2 | 0.05 |
| 世代数 `timeframe` | 10000 | 2000 |
| 1 世代の待ち時間 | 0.001 秒 | 0.15 秒 |
| コメント | 日本語 | 英語 |

### メモ

- `LifeGame_convergence_conway.m` は 10000 世代を毎回描画するので、終わるまで時間がかかります。試すときは `timeframe` を小さくすると早く終わります。
- `init_rate` を変えて何度か実行すると、初期の密度によって収束値がどう変わるかを比べられます。
